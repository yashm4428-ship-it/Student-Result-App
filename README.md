# Student Result Application

A simple frontend lab project built with HTML, CSS and JavaScript.

## Features
- Displays five students' roll numbers, names and marks
- Shows PASS when marks are 40 or above, otherwise FAIL
- Shows total, passed and failed student counts
- Responsive table layout

## Run
Open `index.html` in a web browser.

## Files
- `index.html` - page structure
- `style.css` - styling
- `script.js` - student data and result logic
